## 1. 问题定义（有实测证据）

**照片实际情况**（55 号图 `微信图片_20260914111646_55_155.jpg`，4096×2304）：
物理上只有**一排完整的书**（约 35 本：目的经济/群落化生存/…/社交恐惧心理学），顶部有上一层的窄条、底部有下一层的顶部、层板上有架标 "C912.22/44422 社会团体" 和 "8排6架3层"。

**bug 现象**：整图切块识别（tiles=1，3列×2排=6 块 + 1 整图块）产出 61 本。同一排书被**上排切块**（书脊读成 y≈0.12~0.57）和**下排切块**（y≈0.42~0.78）各读一遍，两遍之间：
- y 带错位约半个行高（dy≈0.24），全局 dedup 的 iou>0.3 / overlap_min>0.5 规则失效（实测 iou 仅 0.09~0.22）；
- 部分书 x 坐标漂移 0.05 以上（实测最右端漂移达 3 倍书宽），x 重叠规则也会漏；
- 下排切块对文字只剩半截的书脊会**幻觉出完全不同的书名**——实测：`社交三力`(x 0.283) 被下带读成 `乌合之众：群体心理研究`(x 0.283)，同一 x 位置、书名毫不相干。这类纯幻觉重复没有任何标题相似性可抓。

- `apps/server/live55_dump.txt` — 修复后某次运行的书籍清单（x/y 区间 + 标题 + 置信度），上带 35 本正确书 + 下带 ~20 本幻觉/碎片
- `apps/server/live55_lower.txt`、`apps/server/live63_dump.txt`

## 2. 已完成的工作（不要重做）

识别管线（`apps/server/main.py` `_recognize_stream`，顺序已固定）：

```
整图块 + 细节切块 并行识别（同一线程池）
  → detail 结果 + frame 补漏(_fill_from_frame, confidence×0.8, source="frame")
  → dedup()            # 全局：iou/overlap_min/同名近似（core/tiles.py）
  → merge_fragments()  # 作者署名"xx著"、纯卷数并入相邻书（core/merge.py）
  → dedup_row_x()      # 物理行内按 x 去重（core/tiles.py，见下）
  → drop_edge_rows()   # 丢弃上下边缘被裁断的半层（core/refine.py）
  → snap_rows()        # 行内 bbox 对齐
  → majority_shelf()   # 架标：切块优先、整图兜底
```

`dedup_row_x` 已有三层规则（`core/tiles.py:175-305`，思路正确，勿推翻）：
1. **同书合并**：标题相等/互为子串且 x 重叠 >0.25；或标题相似度 ≥0.55 且 x 重叠 >0.45；
2. **错位片段吸收**：短标题是长标题子串、短者 ≤ 4 字或不足长者一半、x 间隙 < 3 倍中位书宽、且短者 x 领地已被别人覆盖 >0.3（"双读冗余"判据，防止误吸"活着"这类短名真书和并排复本）；
3. **弱书名丢弃**：x 大半重叠（>0.6）时，纯作者署名/超短/无中文的"弱书名"输给正常书名；
4. **双读带覆盖丢弃**：物理行由多个 y 子带构成时，主带（书最多的子带）书永不丢；次带中 x 领地被主带完全覆盖（≥0.8）的书丢弃。

配套已完成：提示词加 author 字段和"一条书脊一本书/上下裁断半层不输出"规则；`drop_edge_rows`；导出 Excel 加"作者"列；删除接口（DELETE /api/results/{rid}、POST /api/results/delete_all）；Web/小程序端删除按钮与 UI 修复。**测试 161 个全绿。**

## 3. 剩余问题（本次要修的）

按优先级：

### P-A：55 号图仍有 ~20 本幻觉重复（核心）
- 现象：结果 55 本，物理真实约 35 本。多余的是下带幻觉书（乌合之众/社会学的邀请/格调/社会研究方法…），它们与上带真书 **x 重叠但标题完全不相干**。
- 现有"双读带覆盖丢弃"规则应该兜住它们但没兜干净。用 `live55_dump.txt` 逐本核查：
  - 上带（y≈0.12-0.57）35 本是否都被判为主带；
  - 下带每本的 `_x_coverage` 是多少（打印出来），为什么 < 0.8（大概率是 x 漂移 + 上带书被合并后区间变窄导致覆盖率卡在 0.5~0.79）。
- 修法方向（任选，用数据验证）：
  1. 覆盖率阈值从 0.8 降到 0.6~0.7，同时把"次带中领地**未被任何主带书重叠**的书"排除在丢弃外（保住真漏检书）；
  2. 覆盖率计算前对主带 x 区间做膨胀（每侧 +0.5 倍中位书宽），吸收漂移；
  3. 丢弃的次带书写进 stats（如 `dropped_dup_rows`/`dropped_dup_books`）和日志，便于观测误伤。
- **验收**：55 号图结果 33~40 本；`live55_dump.txt` 里下带的"乌合之众/格调/级沟通术/务谈判/超级沟通术/应变场合/交换红利来自 37"全部消失；上带 35 本一本不少（特别注意别把 x 间隙较大的真书"谈判技巧"（历史 coverage 0.52）、"练达"等误杀）；真复本"下一个社会的管理"×2 保留。
